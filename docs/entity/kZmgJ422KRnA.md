## Notes
This board game inspired by Pythagorean proportions has been circulating already in the 1530's in manuscript form, as in the case of [Dialogo sopra la particolare dichiaratione del giuoco di Pitagora](https://nicholascorniaorpheus.github.io/accademia-degli-incompresi/entity/mCuvDnsUYbDe) by [Benedetto Varchi](https://nicholascorniaorpheus.github.io/accademia-degli-incompresi/entity/TdyZG6fXKCLc).
