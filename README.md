# Accademia degli Incompresi

Knowledge base for the fictional academy of Italian transgressive thinkers and artistis of the _Accademia degli Incompresi_. The repository is built built with [KBlight](https://github.com/NicholasCorniaOrpheus/kb-light), a lightweigthed Python package developed by [Nicholas Cornia](https://orpheusinstituut.be/en/research/researchers/nicholas-cornia) as part of his doctorate project [A Whirlpool of Imaginary Sounds](https://orpheusinstituut.be/en/projects/a-whirlpool-of-imaginary-sounds).
